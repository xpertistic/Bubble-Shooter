# 🎯 XShooter

A fast-paced, arcade-style bubble shooter game built for the web. Aim, match, and pop bubbles to clear the board and score maximum points.

---

## 🎮 How to Play

1. **Aim:** Move your pointer or crosshair to align your shot.
2. **Match:** Target clusters of 3 or more bubbles of the same color.
3. **Pop:** Launch your bubble to clear clusters and create chain reactions.
4. **Clear:** Remove all bubbles before they reach the bottom line to win!

---

## ✨ Features

- 💥 **Classic Arcade Gameplay:** Intuitive aim-and-shoot mechanics.
- 🎨 **Vibrant Visuals:** Color-coded bubbles with smooth animations.
- 📱 **Cross-Platform:** Plays smoothly on desktop, tablet, and mobile browsers.
- ⚡ **Lightweight & Fast:** Quick loading times with zero bloat.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (Canvas / React)
- **Game Engine / Logic:** Custom HTML5 Canvas rendering & physics collision logic

---

## 🚀 Local Development Setup

Run the game locally on your machine for development or testing.

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher)
- npm or yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/your-username/xshooter.git](https://github.com/your-username/xshooter.git)
   cd xshooter

```

2. **Install dependencies:**
```bash
npm install

```


3. **Start the local server:**
```bash
npm start
# or
npm run dev

```


4. **Play:** Open your browser and navigate to `http://localhost:3000` (or the local port shown in your terminal).
